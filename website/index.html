阅读使用指南

  1. 安装 Cueport

    下载并解压 ZIP，将 Cueport.app 移入用户的 Applications 文件夹。此版本使用 ad-hoc 签名，未经 Apple 公证。

  2. 复制连接命令

    打开菜单栏中的 Cueport，在 Settings 里设置连接目录并检查 Codex。新建会话选 Copy launch command，恢复对话选 Copy resume command。

  3. 在项目目录运行

    回到对应的 iTerm2 窗口执行命令，按 macOS 提示允许通知。你可以在原会话中回答问题或处理审批。

使用前，你可能想知道

哪些信息会保存在本机？

Cueport 保存定位会话所需的标识和状态。提示词、代码、工具命令和对话正文均不记录。

已经打开的普通 Codex 会话怎么接入？

从 Cueport 设置中复制恢复命令，在原项目目录运行，再选择已有对话。普通启动的终端需要经过这一步才能接入。
