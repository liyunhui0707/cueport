A LITTLE LESS CHECKING

让注意力有一个可靠的落点。

Router 负责关注和定位。决定与操作由你在原始 Codex 会话中完成。

01

状态保持独立

会话可以一边工作，一边等待输入。已查看、已回答和状态未知分别保留，不凭安静时长猜测任务结束。

02

返回准确来源

点击通知或列表前重新核对终端身份。目标关闭、冲突或不可验证时会明确拒绝，不跳到另一个项目。

03

信息留在本机

只保存必要的会话与状态元数据，不保存提示词、代码、工具命令、问题正文或对话文件路径。

BEFORE YOU START

先把边界说清楚。

它会自动接管普通 codex 窗口吗？

当前支持范围是通过应用提供的连接／恢复命令显式接入。直接启动普通 codex 的窗口不会自动附加，也不会冒充已经验证的来源。

连接断开后怎么办？

@@RECOVERY_DESCRIPTION@@

为什么通知可能只出现在通知中心？

macOS 专注模式、屏幕共享通知设置和应用通知样式都会影响横幅。系统接收通知不等于横幅可见；Router 不会绕过这些设置。

如何更新、回退？

目前采用手动更新。发行包中的安装工具先显示计划，应用文件更新保留旧包；回退应用时不恢复旧会话快照。正在运行的 worker 需在方便时自然重连。

这个版本适合什么系统？

当前只分发 Apple Silicon arm64 实验包。源码构建目标为 macOS 14+，更早系统和 Intel 并未因此获得验收。请阅读发行版的实际兼容与验收范围。
