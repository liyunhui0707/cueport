# Changelog

- Keep the menu bar icon compact and let users clear a batch of unconfirmed reminders after checking the original session.
- Close the popover when switching to another app.

## 0.1.0-alpha.5

- Fit an empty menu to its content. Preserve grouped sessions in populated menus.
- Report CLI errors using the invoked name and document installed Hook helper paths.

## 0.1.0-alpha.2 — 2026-11-18

- Bound terminal inventory/version subprocess output, timeout and child cleanup.
- Choose a native arm64 Codex file in Settings; keep future copied commands and
  normal-launch preferences separate from isolated test runs and existing clients.
- Show separate macOS submission and verified notification-return latency summaries.
- Avoid unchanged observation updates, construct the panel on first use, add a
  standard Quit shortcut and improve keyboard focus and accessible status labels.
- Cache the existing menu bar glyph as a template asset; verify 1x/2x alpha, optical
  alignment and size at package time.
- Remove local linker/debug symbols from release packages while preserving global
  symbols and runtime metadata. Retain original RSS failures and artifact-specific
  measurements. Final empty-receiver RSS peaked at 79.328 MiB over 121 samples;
  30 real notification returns had successful-only p95 743.058 ms. Retain the
  safe verification refusal and quota interruption. See docs/quality.md.

## 0.1.0-alpha.1

First public experimental preview of the explicitly connected Codex 0.169.0 +
iTerm2 workflow on Apple Silicon macOS.

- Native grouped attention panel with independent execution/request status.
- Exact registered-source notification return and safe stale/closed refusal.
- Closed/exited source filtering, retained Diagnostics history and direct native
  conversation restoration without first creating a temporary fresh thread.
- Separate daily/test startup identities, saved bridge setup, reviewed app-only
  install/update/rollback and worker/data preservation.
- Bounded build-header reads and direct hexadecimal UUID formatting reduce
  unnecessary diagnostic allocations; resource measurements remain scoped.

Not complete ordinary-CLI P0 support. See [compatibility and known limitations](docs/compatibility.md).
Ad-hoc signed, not notarized; dependencies and accounts are not included.
